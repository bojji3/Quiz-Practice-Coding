Student Information System, 2026

Team Members: Kristina Visaya & Team

Problem Statement

Description, 2026

Many educational institutions struggle with manual record-keeping and inefficient communication between administrators, faculty, and students. This project aims to create a centralized Student Information System that streamlines administrative tasks, facilitates faculty-student interaction, and provides easy access to academic records.

Current Work & Next Step

We have successfully set up the Django project structure, configured URLs, and created the basic template. Our next steps include implementing database models for each module, creating user authentication, and developing the admin dashboard. We will also add CRUD functionality for student records, grade management, and faculty scheduling.

Features

  • Feature 1
    Administrative Module - Manage students, teachers, and courses
  • Feature 2
    Faculty Module - Grade entry, attendance tracking, class management
  • Feature 3
    Administrative Assistant Module - Enrollment processing, document management
  • Feature 4
    Staff Module - Payroll, leave requests, and personnel management
